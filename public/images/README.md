# Bildordner

- `anleitungen/<slug>/` – Bilder je Anleitung. Derzeit **schematische Illustrationen (SVG)**, deutlich als „Illustration“ gekennzeichnet. Es handelt sich ausdrücklich **nicht** um echte Samsung-Bildschirmfotos.
- `screenshots/` – Ablage für **geprüfte, echte Bildschirmfotos** (z. B. eigene Aufnahmen vom eigenen Gerät). Nach dem Ablegen in der Anleitungsdatei unter `bilder` mit `art: "screenshot"` eintragen.
- `kategorien/` – optionale Titelbilder für Kategorien.

Empfehlung für Screenshots: PNG oder WebP, Hochformat, ca. 1080 px breit, persönliche Daten vorher unkenntlich machen.
